# India CPI Data Analysis

## Project Overview

This project analyzes India's Consumer Price Index (CPI) data from 2013 onwards using Microsoft Excel.

The objective is to understand inflation trends, identify major contributing categories, compare inflation before and after COVID-19, and analyze the relationship between crude oil prices and CPI.

## Tools Used

- Microsoft Excel
- Excel formulas
- Data Validation
- Charts & Dashboard
- Statistical analysis

## Key Analysis

### 1. Year-over-Year (YoY) Inflation

Calculated annual inflation trends by comparing CPI values with the previous year.

### 2. Month-over-Month (MoM) Inflation

Analyzed monthly changes in CPI to identify short-term inflation movements.

### 3. Category Analysis

Grouped CPI components into broader categories:

- Food
- Clothing
- Essential
- Health
- Energy
- Luxury

### 4. Pre vs Post COVID Analysis

Compared CPI trends before and after the COVID-19 period to identify changes in inflation patterns.

### 5. Crude Oil vs CPI

Analyzed the relationship between crude oil prices and CPI to understand whether changes in energy prices are associated with changes in consumer inflation.
